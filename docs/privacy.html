Privacy Policy

Last updated: 2026-09-24

Home Calendar Sync is a personal-use application operated solely by the developer for a private home dashboard.

What Google data is accessed

  • Google Calendar (read): upcoming events to display on the dashboard
  • Google Tasks (read/write): list open tasks and mark tasks complete when I check them on the dashboard

How data is used and stored

  • Data is stored on the developer’s own private server (home LAN / Tailscale)
  • OAuth tokens stay in private server config files and are not published to git
  • Google user data is not sold, rented, or shared with third parties
  • Use of Google user data is limited to operating this personal dashboard

Developer contact: the Google account that owns this OAuth project.
