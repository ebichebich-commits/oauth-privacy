Home Calendar Sync

Personal utility for syncing my own Google Calendar events and Google Tasks to a private home dashboard (sensors / schedule display on my LAN).

This app is for a single user (the developer). It is not a public product and is not offered to other customers.

  • Read Google Calendar events shown in my account
  • Read / complete my Google Tasks from the dashboard
  • Optionally create events that I explicitly push from the dashboard
