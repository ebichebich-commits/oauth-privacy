# oauth-privacy

Public pages for Google OAuth consent branding (personal Home Calendar Sync).

## URLs (after GitHub Pages is on)

- Home: `https://ebichebich-commits.github.io/oauth-privacy/`
- Privacy: `https://ebichebich-commits.github.io/oauth-privacy/privacy.html`
- Authorized domain in Google Cloud: `github.io`

## Enable Pages

GitHub → this repo → **Settings** → **Pages** → Source: **Deploy from a branch** → `main` / `/ (root)` → Save.
